# P47-01 Plan: Sheet Preview Review Bridge

## Objective

Turn `sheet_issues.json` from a raw preview artifact into a bounded human review queue that a novice reviewer can follow without confusing preview ids with primary `issues.json` ids.

## Context

- `sheet_issues.json` is preview-only and must not mutate `issues.json` or `review_state.json`.
- `archkg review-state` is intentionally limited to primary issue ids from `issues.json`.
- P46 made the run approachable for novice reviewers; P47 adds the missing bridge for per-sheet preview rows.

## Tasks

1. Add `sheet_issue_review_queue.json` generation for full CLI and Studio review runs.
2. Render the queue in `report.md`, Viewer, workbench artifact status, control sync, release readiness, and novice reviewer guidance.
3. Lock behavior with tests proving the queue is preview-only, bounded, and separate from primary review state.

## Success Criteria

- Full review runs write `sheet_issue_review_queue.json`.
- Queue schema is `sheet_issue_review_queue.v1` and contains `preview_only_no_primary_write`.
- Queue items have preview ids and allowed actions that do not include review-state mutation.
- Existing primary `issues.json` and `review_state.json` behavior remains unchanged.
- Affected tests, ruff, mypy, benchmark suite, release readiness, and full pytest pass.
