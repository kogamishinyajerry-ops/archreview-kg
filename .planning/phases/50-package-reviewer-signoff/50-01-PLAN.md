# P50-01 Plan: Package Reviewer Signoff Notes

## Objective

Add package-level reviewer signoff notes so a receiving reviewer can close a handoff loop as ready, needs_info, or blocked without mutating the original review run.

## Context

- P48 creates read-only handoff packages from existing run artifacts.
- P49 validates package completeness and boundary warnings.
- External review still needs a small package-local place to record whether the package is ready for next review, needs more information, or is blocked.

## Tasks

1. Add package-local `reviewer_signoff.json` and Markdown writer.
2. Add `archkg handoff-signoff PACKAGE_DIR`.
3. Preserve package-only mutation boundaries and explicit non-certification wording.

## Success Criteria

- Signoff writes only inside the handoff package.
- Source run artifacts remain unchanged.
- Status is constrained to `ready`, `needs_info`, or `blocked`.
- Payload schema is `handoff_reviewer_signoff.v1`.
- CLI records reviewer, note, blockers, missing information, and next actions.
- Tests, ruff, mypy, representative package smoke, release readiness, benchmark suite, and full pytest pass.
