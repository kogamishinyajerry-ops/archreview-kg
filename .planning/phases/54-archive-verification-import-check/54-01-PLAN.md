# P54-01 Plan: Archive Verification Import Check

## Objective

Add a receiving-side verification command for handoff packages so reviewers can detect missing, changed, or unexpected package files before using the package.

## Context

P53 creates `handoff_archive_manifest.v1`, but a received package still needs an explicit verification step. Verification must be package-local and integrity-only; it must not mutate source runs or imply compliance.

## Tasks

1. Add tests for clean package verification and checksum drift detection.
2. Implement `handoff_archive_verification.v1`, Markdown output, static index surfacing, and `archkg handoff-archive-verify`.
3. Update README, reviewer playbook, readiness, changelog, roadmap, state, and Notion mirror.

## Success Criteria

- Clean packages verify as `archive_verified`.
- Mutated package artifacts verify as `archive_drift` and make the CLI exit non-zero by default.
- Verification outputs stay inside the handoff package and do not affect source run artifacts.
- Verification artifacts are excluded from repeated checksum comparisons.
- Affected and full tests pass.
