# P52-01 Plan: Manager Checklist Export

## Objective

Add a manager-level package intake checklist so a review manager can quickly decide whether a handoff package is ready for the next review step, needs more information, or is blocked.

## Context

- P48 creates read-only handoff packages.
- P49 validates package quality.
- P50 records reviewer signoff notes.
- P51 gives the package a static browser entry.
- A manager still needs a concise package-level checklist derived from those artifacts without interpreting candidate issues as final compliance findings.

## Tasks

1. Build `handoff_manager_checklist.v1` from package manifest, handoff quality, and reviewer signoff.
2. Add Markdown and JSON writers.
3. Add `archkg handoff-manager-checklist PACKAGE_DIR --manager NAME`.
4. Refresh package `index.html` with manager checklist status.

## Success Criteria

- Complete package + `handoff_ready` + reviewer `ready` yields `manager_ready`.
- Reviewer `needs_info` yields `manager_needs_info`.
- Missing required artifacts, failed package quality, or reviewer `blocked` yields `manager_blocked`.
- Checklist writes only inside the handoff package.
- Source run artifacts remain unchanged.
- Checklist explicitly says it is not a compliance certificate.
- Tests, ruff, mypy, representative package smoke, release readiness, benchmark suite, and full pytest pass.
