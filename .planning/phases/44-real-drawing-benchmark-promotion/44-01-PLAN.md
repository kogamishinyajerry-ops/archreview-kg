# P44-01 PLAN: Promote Real Full-Set Recognition Benchmark

## Objective

Reduce release-readiness warnings by converting a real full-set known_gap into an active recognition benchmark without expanding rule-engine claims.

## Context

P43 made release readiness evidence-gated. The packaged suite still had one known_gap because the Medfield 9-page full plan/elevation set had per-sheet graph evidence for openings, but primary `drawing_understanding.json` still reported `doors=0` and `has_openings=false`.

## Tasks

1. Merge count-level `sheet_graphs.json` evidence into `drawing_understanding.json`.
2. Keep merged evidence clearly marked as per-sheet recognition evidence, not primary graph entities.
3. Promote Medfield full-set from known_gap to active only after benchmark passes.
4. Update readiness docs and planning state.

## Success Criteria

- Full-set `drawing_understanding.json` exposes openings via `sheet_graph_summary`.
- Benchmark expected inventory passes for Medfield full-set.
- Packaged suite reports active=4, pending=1, known_gap=0, failed=0.
- `archkg release-readiness` drops known_gap/generated-heavy warnings and keeps only the remaining pending warning.
- No per-sheet issue is merged into primary `issues.json` or `review_state.json`.
- Targeted tests, ruff, mypy, benchmark suite, release-readiness smoke, and full pytest pass.
