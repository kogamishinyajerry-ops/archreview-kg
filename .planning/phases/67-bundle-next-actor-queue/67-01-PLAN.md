# P67-01 PLAN: Bundle Next-Actor Queue

## Objective

Make a bundle index tell the package owner who should act next across many handoff packages.

## Context

- P60 introduced read-only bundle indexes across multiple handoff packages.
- P63 added cross-package reviewer checklist risk aggregation.
- P66 added package-local ready-to-review runbooks for novice reviewer closeout.
- The remaining manager usability gap is cross-package dispatch: a bundle owner should not need to open every package to know whether reviewer, manager, or archive action is next.

## Tasks

1. Derive a deterministic per-package `next_actor` and `next_action_*` fields from package-local artifacts.
2. Add summary counts for reviewer, manager, archive, and done actors.
3. Add a structured bundle `next_action_queue` while preserving the existing text `next_actions` list.
4. Render next actor/action columns in bundle Markdown and HTML.
5. Add tests covering reviewer, manager, archive, and done routing.

## Success Criteria

- Fresh or incomplete packages route to reviewer action.
- Packages with quality/signoff/checklist complete but no manager checklist route to manager action.
- Packages with manager-ready intake but no archive manifest or verification route to archive action.
- Fully verified packages route to done and do not appear in `next_action_queue`.
- Bundle generation remains read-only and does not write package or source-run artifacts.
