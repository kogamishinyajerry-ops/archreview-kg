# P72-01 Opening Measurement Provenance Plan

## Objective

Add explicit opening measurement provenance to `layout_3d.v1` so reviewers can see which door/window opening dimensions came from graph evidence and which dimensions remain visualization assumptions.

## Context

- P68 introduced graph-derived `layout_3d.json`, `.glb`, and summary as 2.5D navigation evidence only.
- P70 introduced `window_opening` only from explicit graph evidence.
- P71 introduced `properties.opening_semantic` and Viewer/Studio `Opening Semantics`.
- P72 must stay within graph evidence. It must not infer missing dimensions, change the rules engine, promote GLB/IFC previews to BIM truth, or make IfcOpenShell mandatory.

## Tasks

1. Add RED tests for explicit opening measurement provenance.
   - Lock `Door.width_m` as explicit `width_m` provenance.
   - Lock `Door.properties.height_m`, `sill_height_m`, and `head_height_m` as explicit meter provenance.
   - Lock that explicit `height_m` suppresses the corresponding default opening-height assumption for that object.

2. Implement minimal deterministic support in `archkg.layout_3d`.
   - Add `properties.opening_measurement` only for explicit graph fields.
   - Use explicit opening height for the 3D preview object when provided.
   - Keep missing fields as existing visualization assumptions.

3. Surface the evidence.
   - Add `Opening Measurements` counts to `layout_3d_summary.md`.
   - Add Viewer/Studio counts and samples without describing them as compliance facts.

4. Update repo planning/docs and verify.
   - Update README, READINESS, CHANGELOG, ROADMAP, STATE.
   - Run ruff, mypy, targeted tests, and full pytest.

## Success Criteria

- `layout_3d.json` records explicit opening measurement provenance only when the graph carries source fields.
- Missing dimensions continue to be explicit assumptions.
- Viewer/Studio and summary show measurement provenance as preview evidence only.
- No rule-engine, issue lifecycle, IFC dependency, or compliance semantics change.
- Full validation passes before commit.
