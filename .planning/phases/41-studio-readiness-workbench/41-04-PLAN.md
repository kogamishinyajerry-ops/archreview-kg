# P41-04 PLAN: Issue Preview Cross-Highlighting

## Objective

Let reviewers jump from a primary issue row to its visual bbox on the source, entity-overlay, and annotated preview.

## Context

P41-03 added bounded review-state updates. The next usability gap is visual localization: reviewers can see issue IDs and annotated PDFs, but they cannot quickly cross-check one issue against the source/overlay evidence in the workbench.

## Tasks

1. Build a viewer-only issue focus model from primary `issues.json` bboxes and `primitives.json` page dimensions.
2. Render "定位图面" controls on issue rows and a focus rectangle on the layer preview.
3. Keep the feature first-page only until the viewer can render per-page previews.

## Success Criteria

- The focus model omits non-page-0 issues rather than mapping them to the wrong preview.
- Viewer/Studio renders focus controls and a bbox overlay without changing `issues.json`, `review_state.json`, or rule output.
- Tests cover the focus model and rendered UI markers.
- Targeted tests, ruff, mypy, benchmark suite, and full pytest pass.
