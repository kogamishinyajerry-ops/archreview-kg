# P83-01 Package Optional Guidance Note Plan

## Objective

Let novice reviewers record a package-local closeout note for optional guidance
review without turning that note into issue confirmation or a readiness gate.

## Context

P80-P82 made optional opening provenance guidance visible in the runbook, package
index, and bundle index. Reviewers still lacked a package-local artifact for
recording that the optional guidance was reviewed. P83 adds that note layer
without changing the source run, manager intake, or issue lifecycle.

## Tasks

1. Add RED tests proving a CLI command writes package-local optional guidance
   notes and leaves source run artifacts unchanged.
2. Implement `archkg handoff-optional-guidance-note` and
   `handoff_optional_guidance_note.v1` JSON/Markdown output.
3. Render the note in package-root `index.html`.
4. Update roadmap, state, readiness docs, changelog, README, and Notion mirror.

## Success Criteria

- Command writes `handoff_optional_guidance_note.json/.md`.
- JSON includes reviewer, status, note, optional action count/actions, and
  `candidate_issue_confirmation=false`.
- Source run `issues.json` is unchanged.
- Manager checklist status remains unchanged.
- Package index links the note.
- Ruff, mypy, targeted pytest, and full pytest pass.

## Guardrails

- Do not mutate source runs.
- Do not confirm candidate issues or change `review_state.json`.
- Do not add required next actions or manager gates.
- Do not change package readiness.
- Do not treat weak coverage as compliance failure or BIM completeness failure.
