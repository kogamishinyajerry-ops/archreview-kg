# P48-01 Plan: Real-Project Handoff Export Package

## Objective

Create a read-only package from an existing review run so a novice or downstream reviewer can receive the evidence bundle without needing to inspect the whole repo or mutate run state.

## Context

- P46 created novice onboarding artifacts.
- P47 created a bounded per-sheet preview queue.
- A real handoff still needs one directory containing quickstart, report, readiness, review state, preview queue, diff/readiness gates, and visual artifacts when available.

## Tasks

1. Add a handoff package builder that copies selected artifacts out of a run into a standalone package directory.
2. Add `archkg handoff-package RUN_DIR -o PACKAGE_DIR`.
3. Generate `handoff_manifest.json` and `handoff_summary.md` with missing-artifact status and boundary warnings.

## Success Criteria

- The source run is not modified.
- Required artifacts are marked available or missing.
- The package includes copied artifacts under `artifacts/`.
- Boundary warnings preserve candidate issue, preview queue, readiness, and scoped evidence claims.
- Tests, ruff, mypy, representative run, release readiness, benchmark suite, and full pytest pass.
