# P64-01 PLAN: Package-Local Checklist Update

## Objective

Let receiving reviewers record progress on a handoff package checklist without touching the source run or primary issue lifecycle.

## Context

- P62 created `reviewer_task_checklist.json` / `.md` as a fillable seed.
- P63 made bundle index aggregate open checklist risk across packages.
- The remaining gap is package-local mutation: reviewers need a bounded command to update one checklist item inside the package.

## Tasks

1. Add a package-local checklist update writer that validates package manifest and checklist schema.
2. Add `archkg handoff-checklist-update` with `--check-id` or `--ordinal`, reviewer, status, note, and evidence fields.
3. Regenerate `artifacts/reviewer_task_checklist.md` and refresh package `index.html` after update.
4. Add tests and update planning/docs.

## Success Criteria

- Updating a checklist item changes only package-local checklist artifacts and package index.
- Source run checklist, `issues.json`, and `review_state.json` remain unchanged.
- CLI accepts valid statuses and rejects ambiguous item selection.
- Package index and bundle index can read the updated checklist state.
- Targeted tests, lint, mypy, command smoke, benchmark gates, and full pytest pass.
