# P56-01 Plan: Sheet-Aware Issue Focus

## Objective

Remove the first-page-only issue focus limitation in Viewer/Studio while keeping the current static PNG preview boundary honest.

## Context

P41-04 added useful first-page issue cross-highlighting. After P55, the benchmark suite includes more multi-sheet evidence, so the workbench must stop silently omitting or misrepresenting primary issues that carry a non-zero `page_index`.

## Tasks

1. Add failing tests for multi-page issue focus payloads and unmapped page diagnostics.
2. Update `build_issue_focus_view` to normalize issue bboxes against their own page dimensions and report omitted issue reasons.
3. Update Viewer/Studio template behavior so page-0 issues still highlight the preview layer while non-page-0 issues show correct page guidance and PDF review links.
4. Update README, readiness notes, changelog, roadmap, state, and Notion mirror.

## Success Criteria

- Page-0 issue focus remains backward compatible with existing source/overlay/annotated highlighting.
- Non-page-0 primary issues are represented with correct `page_index`, page number, page dimensions, and normalized bbox.
- Non-page-0 issues are not drawn onto the page-0 PNG preview.
- Missing page dimensions are surfaced in `omitted_items`, not silently lost.
- Targeted tests, ruff, mypy, representative viewer smoke, and full pytest pass.
