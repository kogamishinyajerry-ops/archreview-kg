# P53-01 Plan: Archive Manifest Checksums

## Objective

Add a package-local archive manifest so a handoff package can be transferred with deterministic file checksums and a package digest.

## Context

P48-P52 made handoff packages usable by reviewers and managers. The remaining transfer gap is integrity: a receiving reviewer should be able to see what files were packaged and detect drift without treating the checksum as compliance evidence.

## Tasks

1. Add tests for `handoff_archive_manifest.v1` JSON/Markdown output, no source-run mutation, excluded generated files, and static index surfacing.
2. Implement package file SHA-256 entries, deterministic package digest, CLI command, and index integration.
3. Update README, reviewer playbook, readiness, changelog, roadmap, state, and Notion mirror.

## Success Criteria

- `archkg handoff-archive-manifest PACKAGE_DIR --created-by NAME` writes `handoff_archive_manifest.json` and `.md`.
- Archive manifest excludes `handoff_archive_manifest.json`, `handoff_archive_manifest.md`, and package-root `index.html`.
- The source run directory is not mutated.
- The handoff static `index.html` shows archive status and links.
- Affected and full tests pass.
