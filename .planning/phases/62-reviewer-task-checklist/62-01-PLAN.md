# P62-01 PLAN: Reviewer Task Checklist Seed

## Objective

Turn the ordered reviewer task sequence into a fillable checklist seed that a novice reviewer can use to record evidence checked, reviewer_status, notes, and unresolved handoff risk.

## Context

- P61 writes `reviewer_task_sequence.json` / `.md` and renders it in report, Viewer, and handoff packages.
- The next usability gap is execution traceability: a reviewer can see the order, but does not get a task-by-task checklist artifact to carry into handoff.
- Boundaries remain unchanged: no automatic issue confirmation, no `issues.json` mutation, no `review_state.json` mutation, and no preview issue promotion.

## Tasks

1. Add a checklist builder that derives `reviewer_task_checklist.json` / `.md` from `reviewer_task_sequence.json`.
2. Wire checklist generation into CLI and Studio full/inspect-only runs; render it in report and Viewer.
3. Include checklist artifacts in handoff packages and update docs/tests.

## Success Criteria

- Full review runs write `reviewer_task_checklist.json` and `reviewer_task_checklist.md`.
- The checklist contains placeholders for reviewer_status, reviewer, completed_at, reviewer_note, and evidence_checked.
- Report and Viewer expose the checklist without requiring source mutation.
- Handoff packages copy checklist artifacts as required entry evidence.
- Targeted tests, lint, type check, benchmark/release readiness, and full pytest pass.
