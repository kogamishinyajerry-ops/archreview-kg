# P66-01 PLAN: Ready-to-Review Runbook

## Objective

Give a novice reviewer a compact package-local runbook that lists the exact remaining actions before manager intake.

## Context

- P62 creates reviewer checklist seeds.
- P64 lets reviewers update package-local checklist rows.
- P65 prevents manager-ready intake until the reviewer checklist is complete.
- The remaining usability gap is discoverability: a new reviewer still has to infer which command to run next from several package artifacts.

## Tasks

1. Generate `handoff_ready_runbook.json` and `.md` inside each handoff package.
2. Add `archkg handoff-ready-runbook` to refresh the runbook from package-local state.
3. Surface the runbook status and first next actions in package `index.html`.
4. Keep archive checksums stable by excluding the auto-refreshing runbook artifacts.
5. Add tests for open-checklist, ready-for-manager-checklist, and ready-for-manager-intake states.

## Success Criteria

- A fresh package runbook tells the reviewer to run quality/signoff and close checklist rows.
- After checklist completion, the runbook points only to the manager checklist command.
- After manager checklist ready, the runbook has no remaining next actions.
- Runbook generation does not mutate source run artifacts, `issues.json`, or primary `review_state.json`.
- Archive verification remains stable after runbook refreshes.
