# P63-01 PLAN: Bundle Checklist Risk Aggregation

## Objective

Make the multi-package handoff bundle index surface reviewer checklist risk, so a manager can see package readiness and remaining reviewer work in the same static artifact.

## Context

- P60 created `archkg handoff-bundle-index` for multi-package package readiness.
- P62 added `reviewer_task_checklist.json` / `.md` to each full run and handoff package.
- The gap is manager visibility: bundle index did not read checklist artifacts, so open reviewer work was invisible in bundle triage.

## Tasks

1. Read `artifacts/reviewer_task_checklist.json` for each package during bundle index generation.
2. Add per-package checklist summary fields and bundle-level checklist totals.
3. Render checklist status and open item counts in bundle Markdown/HTML.
4. Add regression tests and update planning/docs.

## Success Criteria

- Bundle JSON includes per-package checklist_review_status and open item counts.
- Bundle summary includes checklist open package and item totals.
- Markdown/HTML show checklist risk without hiding existing package readiness.
- Package readiness semantics remain unchanged.
- Targeted handoff bundle tests, lint, mypy, and full pytest pass.
