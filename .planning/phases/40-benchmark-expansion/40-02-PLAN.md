# P40-02 PLAN: Real Multi-Plan Intake Gate

## Objective

Make the benchmark suite track a real multi-sheet plan set before it is ready for scoring, without presenting an unannotated real drawing as a passed capability.

## Context

P40-01 added active multi-plan artifact checks using a deterministic generated fixture. The next gap is real full-set intake: a public or private multi-page architectural drawing needs a reproducible gate that records provenance, missing artifacts, and promotion rules before expected inventory exists.

## Tasks

1. Extend pending suite rows.
   - Preserve existing pending/manual statuses.
   - Expose optional provenance, required artifact list, and promotion rule in suite JSON.

2. Register a real multi-plan intake row.
   - Use the existing Medfield public 9-page plan/elevation PDF source as the real-public full-set intake target.
   - Add provenance that records this as pending fixture bookkeeping, not recognition proof.
   - List the exact artifacts required before promotion.

3. Update documentation and tests.
   - Packaged suite should report active=3, pending=2, known_gap=0, failed=0.
   - README and changelog must clearly say the real full-set row is a pending gate only.

## Success Criteria

- Pending real multi-plan rows are machine-readable enough for the next annotation pass.
- No current artifact or docs claim full real multi-plan recognition success.
- Full benchmark suite remains green.

## Non-Goals

- Do not download or commit the public PDF in this slice.
- Do not create expected inventory from current recognizer output.
- Do not promote the Medfield full set to active or known_gap until full-run artifacts exist.
