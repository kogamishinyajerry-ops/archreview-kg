# P40-03 PLAN: Real Full-Set Known Gap

## Objective

Promote the real Medfield full 9-page plan/elevation set from pending intake to a scored `known_gap` benchmark case.

## Context

P40-02 created a real multi-plan intake gate, but it was still unscored. A real full-set run now exists in `tmp/p40/medfield_full_plan_set_run`. The run produces per-sheet artifacts, but primary `drawing_understanding.json` still reports `doors=0` and `has_openings=false`, which is incompatible with a residential plan set containing door/opening evidence.

## Tasks

1. Commit a reduced full-run artifact snapshot.
   - Include only benchmark-relevant JSON artifacts.
   - Exclude large local artifacts such as `primitives.json`, overlays, and annotated PDF.

2. Add known-gap expected inventory.
   - Require full-set opening evidence in primary drawing understanding.
   - Keep per-sheet graph and issue preview checks so their artifacts remain protected.
   - Keep the suite passing by using `status=known_gap`.

3. Update suite tests and docs.
   - Packaged suite should report active=3, pending=1, known_gap=1, failed=0.
   - The known gap should name failed checks for openings and door evidence.
   - README/CHANGELOG/planning should avoid claiming full-set success.

## Success Criteria

- The real full-set case is scored as known_gap and does not fail the suite.
- The known gap points to real missing evidence, not missing files.
- No generated fixture is used as a substitute for real multi-plan evidence.

## Non-Goals

- Do not fix full-set aggregation in this slice.
- Do not promote the full Medfield set to active.
- Do not merge per-sheet preview issues into primary `issues.json`.
