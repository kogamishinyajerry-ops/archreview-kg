# P69-01 Layout IFC Export Skeleton

## Objective

Add an explicit, optional IFC preview export lane for the P68 `layout_3d.v1` evidence model without changing default review runs, rule-engine output, or review-state semantics.

## Context

P68 produces `layout_3d.json`, `layout_3d_summary.md`, and `layout_3d.glb` from graph-backed 2.5D evidence. P69 should let reviewers hand off that evidence through a lightweight IFC preview artifact when IfcOpenShell is installed, while keeping missing optional dependencies as a clean degradation path.

## Tasks

1. Add `archkg.ifc.layout_exporter` with `layout_ifc_export.v1` report schema and status values: `exported`, `dependency_missing`, `blocked`, and `failed`.
2. Add `archkg ifc export-layout --layout ... --out ... --report ... --markdown ...` that reads only `layout_3d.json`.
3. Map `floor_slab`, `wall`, `room_volume`, `corridor_volume`, `door_opening`, and `stair_placeholder` into IFC preview entities; skip `dimension_anchor` into report counts.
4. Cover success with fake IfcOpenShell modules, missing dependency, and blocked layout with tests.
5. Add optional `layout.ifc`, `layout_ifc_export.json`, and `layout_ifc_export.md` artifacts to Viewer/Studio, handoff packages, and control sync.
6. Update README, READINESS, CHANGELOG, ROADMAP, STATE, and phase summary.

## Success Criteria

- Missing IfcOpenShell returns exit code 1, does not generate `layout.ifc`, and writes `dependency_missing` reports when requested.
- Blocked `layout_3d` returns exit code 1, does not generate `layout.ifc`, and writes `blocked` reports.
- Fake dependency success writes non-empty IFC preview content plus JSON/Markdown reports.
- Viewer/Studio explicitly show IFC preview as optional and not review-grade BIM.
- Handoff/control-sync copy or mirror optional IFC artifacts when present but do not block when missing.
- `ruff`, `mypy archkg`, targeted tests, and full pytest pass.

## Guardrails

- Do not install or require IfcOpenShell by default.
- Do not hand-write a full IFC/STEP stack.
- Do not add `layout.ifc` to default `archkg review` outputs.
- Do not use GLB/IFC preview as a compliance input.
- Do not claim review-grade BIM, neural floorplan reconstruction, window recognition, boolean void subtraction, or multi-floor stacking.
