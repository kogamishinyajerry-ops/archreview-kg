# P65-01 PLAN: Manager Checklist Reviewer Gate

## Objective

Require package-local reviewer checklist completion before a handoff package can reach manager-ready intake.

## Context

- P62 created a fillable reviewer task checklist seed.
- P63 made bundle index expose open checklist risk across packages.
- P64 let reviewers update individual checklist rows inside a handoff package.
- The remaining gap is manager intake: `handoff-manager-checklist` should not report `manager_ready` while reviewer checklist rows remain open.

## Tasks

1. Load `artifacts/reviewer_task_checklist.json` inside `build_handoff_manager_checklist`.
2. Add checklist status and open/blocked/needs-info counts to manager checklist summary and Markdown.
3. Add a `reviewer_task_checklist_complete` manager checklist item that passes only when checklist status is complete.
4. Add tests for both ready and open-checklist manager intake paths.
5. Update docs, roadmap, readiness notes, and Notion mirror.

## Success Criteria

- Quality ready plus reviewer signoff ready is not enough for `manager_ready` when reviewer checklist rows remain open.
- Completed or explicitly skipped preview rows allow the reviewer checklist item to pass.
- Open or needs-info checklist rows produce `manager_needs_info`.
- Blocked or missing checklist state blocks manager intake.
- Source run artifacts, `issues.json`, and primary `review_state.json` remain untouched.
