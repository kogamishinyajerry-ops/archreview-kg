# P58-01 Plan: Handoff Preview Asset Completeness

## Objective

Make P57 multi-page preview assets survive handoff packaging so novice reviewers can open a package-local static viewer without broken image/PDF links.

## Context

P57 added `preview_pages.json` plus multi-page source/annotated PNGs in run directories. `archkg handoff-package` previously copied only a fixed artifact list, so package-local static viewer pages could reference preview assets that were not copied into `artifacts/`.

## Tasks

1. Add failing handoff tests for multi-page preview asset copying and missing referenced preview images.
2. Extend the handoff artifact list with `source.pdf`, `preview_pages.json`, and `annotated_preview.png`.
3. Treat `preview_pages.json` as a visual dependency manifest and copy every referenced page image into the handoff package.
4. Mark referenced preview assets as conditionally required so missing page images block handoff quality.
5. Update docs, readiness notes, roadmap, state, and Notion mirror.

## Success Criteria

- Handoff packages include package-local `preview_pages.json`, `source.pdf`, legacy preview PNGs, and all page images referenced by the preview manifest.
- Package quality fails when `preview_pages.json` references a missing page image.
- Source run artifacts are not mutated.
- Existing handoff package quality/signoff/manager/archive flows remain green.
- Targeted tests, ruff, mypy, representative multi-page package smoke, benchmark suite, release-readiness reference, and full pytest pass.
