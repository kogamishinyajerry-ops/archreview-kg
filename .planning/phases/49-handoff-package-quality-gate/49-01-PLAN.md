# P49-01 Plan: Handoff Package Quality Gate

## Objective

Add an independent quality gate for read-only handoff packages so external review does not start from a broken or misleading artifact bundle.

## Context

- P48 can generate `handoff_manifest.json`, `handoff_summary.md`, and copied artifacts.
- A package can still become incomplete if files are moved, deleted, or generated from a partial run.
- The gate must validate package completeness and boundary warnings without touching the source run.

## Tasks

1. Add `build_handoff_package_quality(package_dir)` and JSON/Markdown writers.
2. Add `archkg handoff-check PACKAGE_DIR`.
3. Check manifest schema, read-only mutation policy, required artifacts, copied file existence, and boundary warnings.

## Success Criteria

- Complete packages return `handoff_ready`.
- Missing required copied artifacts return `not_ready` and non-zero CLI exit.
- Reports use schema `handoff_package_quality.v1`.
- Gate does not mutate source run or package evidence files other than explicit output report paths.
- Tests, ruff, mypy, representative package smoke, release readiness, benchmark suite, and full pytest pass.
