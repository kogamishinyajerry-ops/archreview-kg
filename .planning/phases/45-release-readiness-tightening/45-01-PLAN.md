# P45-01 PLAN: Clear Packaged Suite Pending Row

## Objective

Remove the last packaged benchmark pending/manual row without weakening the evidence gate or expanding real-drawing readiness claims.

## Context

P44 promoted the Medfield full public plan/elevation set to active recognition benchmark, leaving one `sample_clean_full` toy row marked `manual_run_required`. That row prevented `archkg release-readiness` from reaching `evidence_ready` even when the representative run artifacts were complete.

## Tasks

1. Generate a deterministic `sample_clean_full` run from `samples/sample_clean.pdf` with demo project, room, and stair schedules.
2. Commit the minimal benchmark artifacts under `samples/understanding_benchmarks/toy/`.
3. Convert the manifest row from `manual_run_required` to active with explicit provenance and scope notes.
4. Update packaged suite and release-readiness tests so active=5, pending=0, known_gap=0 is locked.
5. Update README, readiness notes, changelog, and planning state with the narrower P45 claim.

## Success Criteria

- `sample-clean-full-active` passes the existing `sample_clean_full.json` expected inventory.
- Packaged suite reports active=5, pending=0, known_gap=0, failed=0.
- `archkg release-readiness` can output `evidence_ready` when a representative run includes all core and maturity artifacts.
- Documentation states that `evidence_ready` is scoped to benchmarked drawing classes only.
- Targeted tests, ruff, mypy, benchmark suite, release-readiness smoke, and full pytest pass.
