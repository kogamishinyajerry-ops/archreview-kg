# P51-01 Plan: Static Handoff Package Review View

## Objective

Make a generated handoff package directly consumable by a novice review engineer through a static browser page.

## Context

- P48 creates a read-only handoff package with copied artifacts.
- P49 validates package completeness.
- P50 records package-local reviewer signoff notes.
- A receiving reviewer still has to inspect several files manually; a package-root static `index.html` should provide the first entry without running Studio or a server.

## Tasks

1. Render package-root `index.html` from `handoff_manifest.json`.
2. Surface package boundary warnings, artifact links, quality status, and reviewer signoff status.
3. Refresh the static page after `handoff-check` and `handoff-signoff`.
4. Preserve read-only handoff semantics and source-run non-mutation.

## Success Criteria

- `archkg handoff-package` writes `index.html` at package root.
- `archkg handoff-check` updates the static page with quality state.
- `archkg handoff-signoff` updates the static page with reviewer signoff state.
- The static page links to copied artifacts and repeats compliance-boundary warnings.
- Source run artifacts remain unchanged.
- Tests, ruff, mypy, representative package smoke, release readiness, benchmark suite, and full pytest pass.
